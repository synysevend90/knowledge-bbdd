Instalación de SQL Server 2025 Developer

Procedimiento guiado · En curso · Instalación independiente
Estado: guía en curso. La secuencia recuperada llega hasta la selección de características del motor. Las pantallas posteriores y la verificación final aún deben contrastarse con el resultado real de la instalación.

Objetivo

Documentar la instalación independiente de SQL Server 2025 Developer en Windows a partir de las pantallas reales del Centro de instalación. La instalación de SSMS se explica en un procedimiento separado.

Procedimiento confirmado

1. Iniciar la instalación

Abre el Centro de instalación de SQL Server 2025 y comienza una instalación independiente de SQL Server. La primera pantalla del asistente confirma el inicio del procedimiento.

2. Descargar el medio e iniciar el Centro de instalación

Continúa con la descarga del medio de instalación y abre el Centro de instalación desde el asistente. Sigue los nombres y las opciones que aparecen en la versión descargada.

3. Seleccionar Developer

Selecciona la edición Developer para el entorno de aprendizaje y desarrollo documentado. Comprueba la edición en pantalla antes de continuar.

4. Omitir Microsoft Update durante la instalación

Deja deshabilitada la búsqueda de actualizaciones de Microsoft en este paso. La opción se omitió en el procedimiento documentado y no es necesaria para completar la instalación.

5. Revisar las reglas y continuar sin cambiar el firewall

Revisa las reglas de instalación. Si aparece una advertencia relacionada con el Firewall de Windows, se puede continuar sin cambiar la configuración del firewall para esta instalación local del laboratorio. No desactives el firewall ni crees reglas manuales como parte de este procedimiento.

6. Omitir la integración con Azure

En la configuración relacionada con Azure, no habilites una integración que no forme parte del objetivo de esta instalación local.

7. Seleccionar las características del motor

En la selección de características, céntrate en el motor de base de datos de SQL Server. Revisa la pantalla real antes de marcar componentes adicionales y deja sin seleccionar los que no necesites.

Continuación pendiente

La secuencia recuperable termina en la selección de características. Antes de añadir los pasos siguientes, hay que contrastar en el equipo la configuración de instancia y del servidor, la preparación de la instalación, el progreso, el resultado final y las comprobaciones posteriores.

Verificación para cerrar la guía

Marca la guía como completada cuando la instalación confirme que ha finalizado y se verifique que el servicio o la instancia instalada aparecen en el equipo. Hasta entonces, este artículo permanece en curso.

Privacidad de las capturas

Antes de publicar capturas, oculta nombres de equipo, usuarios, identificadores y cualquier otro dato privado visible.
