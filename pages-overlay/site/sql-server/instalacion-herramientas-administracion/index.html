Instalación de las herramientas de administración de SQL Server

Procedimiento guiado · Completado y verificado · SSMS 22.10.2
Estado: instalación completada y verificada. Se omite el inicio de sesión con una cuenta de Microsoft o GitHub. La guía termina cuando SSMS abre y muestra el cuadro Conectar; la conexión a una instancia se documenta por separado.

Objetivo y entorno

Instalar SQL Server Management Studio (SSMS), la herramienta gráfica para conectarse a instancias y administrar SQL Server. El procedimiento se realizó en Windows desde el Centro de instalación de SQL Server 2025 y el instalador de SSMS 22. La versión comprobada fue 22.10.2.

Procedimiento

1. Abrir el Centro de instalación

Desde el menú Inicio, busca sql y abre Centro de instalación de SQL Server 2025 (64 bits). Que aparezcan otras herramientas en los resultados no confirma que SSMS ya esté instalado.

2. Abrir la descarga de herramientas de administración

En el panel izquierdo, selecciona Instalación y pulsa Instalar las herramientas de administración de SQL Server. El Centro indica que se necesita conexión a Internet y que el enlace permite acceder a las descargas de SSMS, SQL Server Profiler y el Asistente para la optimización de bases de datos.

3. Descargar el instalador de SSMS

En la página oficial de Microsoft Instale SQL Server Management Studio, descarga el instalador de SQL Server Management Studio 22. El archivo vs_SSMS.exe inicia el Instalador de Visual Studio; Microsoft no ofrece un MSI independiente para este procedimiento.

La página consultada y el instalador mostraban SSMS 22. Si la versión disponible cambia, utiliza la que indique la página oficial.

4. Revisar componentes y cargas de trabajo

En el Instalador de Visual Studio, comprueba que Componentes principales de SSMS aparece en Detalles de la instalación. La pestaña Cargas de trabajo ofrece opciones adicionales de Asistencia de IA, Inteligencia empresarial, Híbrido y migración, Herramientas de código y Database DevOps. Para instalar SSMS con sus componentes principales, deja las cargas opcionales sin marcar salvo que necesites alguna.

La pantalla de este procedimiento indicaba 3,83 GB de espacio necesario, la ruta predeterminada C:\Program Files\Microsoft SQL Server Management Studio 22\Release y la opción Instalar durante la descarga.

5. Instalar SSMS

Pulsa Instalar y espera a que terminen la descarga y la instalación. En este procedimiento, el instalador mostró Instalación finalizada y confirmó que SSMS 22.10.2 estaba actualizado.

6. Cerrar el aviso de finalización

Pulsa Aceptar en el aviso Instalación finalizada. El instalador recomienda reiniciar Windows para limpiar los archivos restantes.

7. Omitir el inicio de sesión

Al abrir SSMS por primera vez puede aparecer la pantalla Iniciar sesión en SQL Server Management Studio. Como este procedimiento no vincula ninguna cuenta, pulsa Omitir y agregar cuentas más tarde.

8. Confirmar que SSMS se inicia

SSMS abre y muestra el cuadro Conectar. Esta pantalla confirma que la aplicación está instalada y puede iniciarse. No introduzcas un nombre de servidor: la conexión a una instancia queda fuera del alcance de este artículo.

Verificación

  • El Instalador de Visual Studio confirmó Instalación finalizada.
  • En la pestaña Instalado aparecía SQL Server Management Studio 22, versión 22.10.2.
  • SSMS se inició y mostró el cuadro Conectar.

Privacidad de las capturas

Las capturas del cuadro Conectar pueden mostrar el nombre del equipo y el usuario de Windows. Oculta esos datos antes de publicar una captura.
