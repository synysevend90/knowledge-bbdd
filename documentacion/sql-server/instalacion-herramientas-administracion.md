# Instalación de las herramientas de administración de SQL Server

> **Estado:** documentación en curso. El punto de partida se ha comprobado en una captura de Windows; los pasos de instalación todavía están pendientes de verificar durante el procedimiento.

## Objetivo

Documentar la instalación de las herramientas de administración de SQL Server 2025 en Windows, indicando qué componentes se instalan, cómo iniciar el proceso y cómo comprobar que quedan disponibles.

## Punto de partida

En el menú Inicio de Windows, busca `sql`. En la captura inicial aparecen estas aplicaciones:

- Centro de instalación de SQL Server 2025 (64 bits)
- Administrador de configuración de SQL Server 2025
- Informes de errores y de uso de SQL Server 2025
- Importación y exportación de datos (64 bits) de SQL Server 2025

La captura confirma que el Centro de instalación y esas herramientas aparecen en los resultados de búsqueda. **Todavía no confirma** qué herramienta concreta se instalará en esta guía ni que SQL Server Management Studio esté instalado.

## Procedimiento

### 1. Abrir el Centro de instalación de SQL Server

Desde los resultados de búsqueda de Windows, abre **Centro de instalación de SQL Server 2025 (64 bits)**.

**Resultado que se debe comprobar:** se abre el Centro de instalación de SQL Server 2025. El siguiente paso se añadirá después de revisar esa pantalla.

> **Pendiente de captura:** ventana del Centro de instalación abierta. No continuar con opciones inferidas; confirmar en pantalla la sección y el enlace adecuados para instalar las herramientas de administración.
